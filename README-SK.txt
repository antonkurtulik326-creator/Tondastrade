TRADE RADAR v2 – nákupné signály
================================
Nahraď celý obsah GitHub repozitára týmito súbormi (zmaž starý index.html, sw.js, manifest.webmanifest, ikony) a daj Commit.
GitHub Pages ostane rovnaké. Na telefóne po aktualizácii zavri a znova otvor appku (prípadne odinštaluj a nainštaluj).

Súbory: index.html, style.css, engine.js (logika signálov + backtest), app.js, sw.js, manifest.webmanifest, ikony.

Dáta: Binance (verejné, bez kľúča). Akcie/ETF cez Twelve Data (vlastný bezplatný kľúč v Nastaveniach).
Aplikácia nezadáva obchody. Nie je to investičné poradenstvo.
